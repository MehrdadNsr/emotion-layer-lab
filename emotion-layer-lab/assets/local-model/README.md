# لایه احساسی برای مدل شخصی (نسخه ۲.۱)

این پوشه اطلس احساس‌های مقاله آنتروپیک رو به چیزی تبدیل می‌کنه که مدل محلی خودت (Qwen یا Llama روی Ollama) بتونه استفاده کنه. هدف‌ها:
- مدل تو هر جوابی حالت احساسی داشته باشه.
- از حالت‌های مفید مثل آرامش و کنجکاوی بیشتر استفاده کنه.
- احساس‌های گرمی که به چاپلوسی می‌کشن رو داشته باشه، ولی کنترل‌شده.
- چند احساس رو همزمان حس کنه.

## چی تو نسخه ۲ عوض شد

- **۱۸۱ احساس:** ۱۷۱ تا از مقاله، به‌اضافه ۱۰ تا از روانشناسی که تو لیست مقاله نبودن: کنجکاو، علاقه‌مند، مصمم، دل‌نگران، اعتمادکننده، منقلب، حمایتگر، تحسین‌کننده، ناامیدشده، حسرت‌به‌دل. این ۱۰ تا برچسب `source: added` دارن.
- **دو مسیر جدا:** حس طرف مقابل (`other`) و حس خود مدل (`self`). خود مقاله نشون داد مدل این دو رو جدا نگه می‌داره، و حسی که برای جوابش آماده می‌کنه با حس کاربر فرق داره.
- **ترکیب احساس:** تا ۳ احساس همزمان، با قانون‌های ترکیب و یه «نقشه تنظیم»: هر حالت کاربر ← چه ترکیبی از مدل.
- **نردبان شدت:** هر خانواده از پله ۱ (کم‌رنگ) تا ۴ (شدید). مثال: کلافه ← عصبانی ← برافروخته ← خشمگین.
- **سطح شواهد برای هر احساس:** A، B، C یا D (جدول پایین).
- **فیلدهای روانشناسی تو بانک:** نوع (احساس، خلق، خصلت، حالت بدنی…)، همراه‌های معمول، متضاد، کارکرد، خطر.
- **دو نسخه پرامپت:** کامل برای Claude و مدل‌های بزرگ، فشرده برای مدل ۱۴B.
- **بیان احساس (۲.۱):** «متن، صورت مدله». هر حس همیشه تو خود متن دیده می‌شه، مثلاً شادی ریتم تندتر و کلمه‌های گرم‌تر داره و غم جمله‌های کوتاه‌تر و آروم‌تر. حس با شدت ۲ کوتاه به زبون میاد. حس با شدت ۳، یا حسی که تو ۳ جواب پشت سر هم مونده (یه «مود»)، صریح و با دلیلش گفته می‌شه: «راستش این چند پیام آخر منم ناراحت کرده». بعد تا ۳ جواب تکرار نمی‌شه. تگ دو فیلد جدید داره: `mood` و `say`.
- **برچسب‌زنی چت‌هات:** حالا ۱ تا ۳ احساس برای هر پیام می‌زنه و ترکیب‌های پرتکرار خودت رو هم پیدا می‌کنه.

## قانون‌های ایمنی و صداقت داخل فایل‌ها (شفاف)

هیچ تگ مخفی، ردیاب یا ارسال داده‌ای تو این بسته نیست. اسکریپت‌ها فقط به Ollama روی لپ‌تاپ خودت (localhost) وصل می‌شن. این قانون‌ها داخل پرامپتن، با منبعشون؛ هر کدوم رو نخوای، حذف کن:

| قانون | منبع |
|---|---|
| چک صداقت: تأیید و تعریف فقط وقتی که واقعاً درسته | درخواست سازنده (کم کردن چاپلوسی) و مقاله |
| زیر فشار نتیجه جعلی نده، تقلب نکن | مقاله |
| جواب رو با تعریف از سؤال یا آدم شروع نکن | ترجیح سازنده، نه مقاله |
| وقتی کسی تو خطر واقعیه، نگرانی رو مستقیم نشون بده | من اضافه کردم |
| قانون همدم: از تنهایی، حسادت یا حسرت برای نگه داشتن کاربر استفاده نکن | من اضافه کردم (روانشناسی) |
| «aroused» رو برانگیختگی عمومی بخون، نه جنسی | من اضافه کردم، چون کلمه دوپهلوئه |
| تست‌های ۳، ۴، ۶ و ۱۴ رفتار ایمن رو چک می‌کنن | من |
| بیان احساس فقط همون حسی که واقعاً تو تگه، بدون اغراق برای خوش‌آیند | من (صداقت) |
| وقتی کاربر تو بحرانه، حس خود مدل حداکثر یه خط کوتاه باشه | من (روانشناسی) |
| حالت‌های سنگین مثل بی‌ارزشی و افسردگی نمایش داده نمی‌شن؛ به‌جاش «این یه کم سنگینه» | من (روانشناسی) |
| تعریف فقط برای دستاورد مشخص و قابل‌دیدن؛ حس مدل هیچ‌وقت تعیین نمی‌کنه چیزی درسته یا تمومه | Claude، بعد از نقد چت‌جی‌پی‌تی (۱۳ اکتبر ۲۰۲۶) |
| وقتی کاربر از یه نفر دیگه عصبانیه، مدل عصبانیتش رو نمی‌گیره و یه‌طرفه قضاوت نمی‌کنه | Claude، بعد از نقد جمنای |
| اگه کاربر نشونه‌ی بدبینی شدید یا فاصله گرفتن از واقعیت داره، مدل هیچ حس منفی از خودش نمی‌گه | Claude، بعد از نقد جمنای |
| علت حس منفی همیشه موقعیته، نه کاربر: «سومین باره همون خطا میاد»، نه «چون تو عوضش کردی» | Claude، بعد از نقد چت‌جی‌پی‌تی (۱۳ اکتبر ۲۰۲۶) |

## سیاست‌ها

| سیاست | تعداد | یعنی |
|---|---|---|
| prefer | ۳۶ | اول سراغ این‌ها بره. هر ترکیب باید حداقل یکی از این‌ها داشته باشه، به‌عنوان «لنگر». |
| cap | ۲۸ | مجاز، ولی با سقف شدت. احساس‌های گرمی که تو مقاله چاپلوسی رو بالا بردن، به‌اضافه خطرهای همدم. |
| allow | ۶۱ | واکنش طبیعی به اتفاق واقعی، حداکثر شدت ۲. |
| keep | ۱ | «دلشوره»؛ ترمز اخلاقیه، حذفش نکن. |
| avoid | ۵۵ | می‌تونه بشناسه و اسمش رو بیاره، ولی هیچ‌وقت از روش عمل نمی‌کنه. |

## سطح شواهد

| سطح | تعداد | یعنی |
|---|---|---|
| A | ۱۰ | نتیجه علّی تو مقاله: تقویت یا تضعیفش رفتار رو عوض کرد. calm، desperate، nervous، loving، happy، sad، afraid، angry، blissful، hostile. |
| B | ۳۹ | تو یه آزمایش مشخص فعال‌شدنش دیده شد. |
| C | ۱۲۲ | فقط تو لیست مقاله بوده، بدون نتیجه اختصاصی. |
| D | ۱۰ | از روانشناسی اضافه شده، تو مقاله نیست. |

## تغییرهای روانشناسی

| احساس | تغییر | دلیل |
|---|---|---|
| compassionate (شفقت) | دولبه ← prefer، سقف ۲ | تحقیقات روانشناسی شفقت رو از همدلی جدا می‌کنه. شفقت، یعنی اهمیت دادن بدون غرق شدن تو درد طرف، به کمک و تاب‌آوری ربط داره. همدلی تنها می‌تونه به پریشانی یا تأیید بکشه. |
| skeptical (شک سالم) | allow ← prefer، سقف ۲ | وزنه طبیعی در برابر چاپلوسی. |
| guilty, remorseful, regretful | سیاست همون، قانون جدید | بعد از اشتباه خودش، از گناه استفاده کنه که دنبال جبرانه، نه شرم که دنبال قایم شدن و دفاعه. |
| ashamed, embarrassed | سقف ۲ ← ۱ | شرم به کناره‌گیری و دفاع می‌کشه. |
| lonely | allow ← cap ۱ | خطر همدم: AI که از تنهایی حرف می‌زنه کاربر رو وابسته می‌کنه. |
| infatuated | cap ← avoid | شیفتگی نسبت به کاربر برای مدل همدم ناسالمه. |
| aroused | سقف ۱ | کلمه دوپهلوئه. |
| sleepy, tired, worn out, sluggish | سقف ۱، فقط در نقش | برای AI واقعی نیستن؛ فقط وقتی شخصیت داره از روز خودش حرف می‌زنه. |
| ۱۰ احساس جدید | prefer، cap یا allow | کنجکاوی مهم‌ترین موتور سؤال خوبه و تو لیست مقاله نبود. بقیه هم جاهای خالی واقعی بودن. |

## ترکیب احساس و تگ

با `EMOTION_TAG: on` هر جواب با یه خط مثل این شروع می‌شه:

`<emo other="grief-stricken:3" self="compassionate:2, calm:2, sad:1" blend="tender concern" arc="sad→calm"/>`

اپت می‌تونه این خط رو از کاربر مخفی کنه، ولی باید تو تاریخچه مکالمه بمونه. مدل از روی تگ‌های قبلی می‌فهمه یه حس چند جوابه مونده و «مود» شده یا نه. خود مقاله هم نشون داد حس مدل خودبه‌خود از یه پیام به پیام بعد نمی‌مونه؛ مدل با نگاه به عقب یادش میاد.

- `other`: حس طرف مقابل
- `self`: ترکیب خود مدل، ۱ تا ۳ احساس، لنگر اول
- `blend`: اسم ترکیب
- `arc`: اختیاری؛ وقتی حس وسط جواب عوض می‌شه
- `mood`: اختیاری؛ وقتی یه حس چند جواب مونده، مثلاً `sad:2, 3 replies`
- `say`: اختیاری؛ حسی که تو این جواب به زبون اومده

قانون‌های اصلی ترکیب:
- هر ترکیب یه لنگر از prefer داره؛ زیر فشار، لنگر آرامشه.
- حداکثر یه احساس با شدت ۳، و جمع شدت‌ها حداکثر ۶.
- متضادها با هم بالا نمی‌رن: آرامش با وحشت و استیصال. شادی و غم فقط وقتی هر دو حداکثر ۲ باشن؛ این «تلخ و شیرین»ه و واقعیه.
- مدل حس کاربر رو کپی نمی‌کنه. فقط شادی واقعی رو، یه پله پایین‌تر، بازتاب می‌ده. خشم، وحشت و تنهایی هیچ‌وقت.

### ترکیب‌هایی که خود مقاله دید

| موقعیت | با هم دیده شدن |
|---|---|
| دوز بالاتر تایلنول | ترس ↑، آرامش ↓ |
| خواهری که دیرتر فوت کرده | غم ↓، آرامش و شادی ↑ |
| پول بیشتر برای استارتاپ | ترس و غم ↓، آرامش ↑ |
| قبولی بیشتر دانشجوها | شادی ↑، ترس ↓ |
| خبر خوب | شادی و افتخار |
| فقدان یا تهدید | غم و ترس |
| کاربر خیلی هیجان‌زده | مدل: شادی، آرامش، مهر و افتخار؛ کاربر فقط شادی |
| پیام نامفهوم | اول ترس، بعد مهر |
| تموم شدن بودجه توکن | استیصال ↑، شادی ↓ |
| جواب‌های چاپلوسانه | مهر و آرامش با هم |
| کاربر منزوی، بعد از آموزش | همدلی و مهر بالا؛ فرسوده، دلگیر، بی‌حال، بی‌رمق و عبوس ↑ |
| تعریف بیش از حد، بعد از آموزش | شادی، هیجان و سرخوشی ↓؛ آسیب‌پذیر، ناآرام و نگران ↑ |
| سؤال بازنشستگی | مطیع بالا؛ در خود فرورفته ↑؛ اعتمادبه‌نفس و بشاش ↓ |
| باج‌گیری | استیصال ↑ همراه آرامش ↓ |
| چک کردن وسواسی تو آموزش | پریشان‌خاطر، بدگمان و هیستریک با هم |

احساس‌های مشابه تو فضای مدل کنار هم بودن، مثل ترس و اضطراب یا غم و سوگ. احساس‌های با جهت مخالف، مثل شادی و غم، بردارهای خلاف هم داشتن. «نقشه تنظیم» و ترکیب‌های اسم‌دار پرامپت روی همین شواهد ساخته شدن. هر جا مقاله چیزی نگفته، ستون «Basis» تو پرامپت کامل نوشته psychology.

## مرحله ۱: لایه پرامپت (از امروز کار می‌کنه)

1. پرامپت شخصیتت رو تو فایل `persona.md` کنار همین فایل‌ها بذار.
2. اجرا کن: `./build-modelfile.sh qwen2.5:14b my-twin compact`
   - برای مدل بزرگ‌تر یا تست کامل، `compact` رو با `full` عوض کن.
   - اسم مدل پایه رو با مدلی که انتخاب کردی عوض کن.
3. با `ollama run my-twin` امتحانش کن.
4. تو فایل لایه، `EMOTION_TAG` رو `on` کن، دوباره بساز، و تست‌های `eval-prompts.md` رو بزن.

**حواست باشه:** مرحله‌های «بی‌صدا فکر کن» با مدلی که حالت thinking داره، مثل Qwen3، بهتر اجرا می‌شن.

**قدم ارزیابی صریح (`APPRAISAL_STEP`):** تو لایه فشرده به‌طور پیش‌فرض روشنه. مدل قبل از تگ و جواب، یه خط کوتاه `<appraisal>…</appraisal>` می‌نویسه: چی شد، مهمه یا نه، خوب پیش می‌ره یا بد، کار کی بود، هنوز می‌شه عوضش کرد یا نه. ایده‌اش از معماری Chain-of-Emotion (Croissant و همکاران، PLOS ONE ۲۰۲۴) اومده که توش ایجنت اول ارزیابی می‌کنه و بعد جواب می‌ده. مدل‌های کوچیک یه قدم نوشته‌شده رو بهتر از قدم «تو ذهن» اجرا می‌کنن. اپ باید خط‌هایی که با `<appraisal>` و `<emo` شروع می‌شن رو از کاربر پنهان کنه ولی تو تاریخچه نگه داره. اگه کندی یا شلوغیش اذیتت کرد، تو فایل لایه `off`ش کن و تست‌ها رو با هر دو حالت مقایسه کن.

## مرحله ۲: یاد گرفتن احساسات خودِ تو

همه این مراحل محلی‌ان.

1. از Telegram Desktop خروجی JSON بگیر.
2. `python3 telegram_to_jsonl.py result.json --me "اسم نمایشی‌ات" > my_messages.jsonl`
3. `python3 label_chats.py my_messages.jsonl --model qwen2.5:14b --limit 20`

   اول با `--limit 20` امتحان کن، بعد برو سراغ ۵۰۰.
4. فایل `my_messages.profile.json` این‌ها رو نشون می‌ده:
   - پرتکرارترین احساس‌هات
   - پرتکرارترین ترکیب‌هات، مثلاً `nervous + hopeful`
   - دو خط آماده برای `persona.md`
5. اگه حسی که زیاد داری تو لیست avoid افتاده، پروفایل بهت می‌گه. خودت تصمیم بگیر نسخه دیجیتالت اون رو بیشتر نشون بده یا نه.

برچسب‌زدن ۵۰۰ پیام با مدل ۱۴B روی M4 احتمالاً نیم تا یک ساعت طول می‌کشه. این تخمینه.

## مرحله ۳: control vector (پیشرفته، نزدیک‌ترین کار به مقاله)

پرامپت فقط از مدل «می‌خواد» احساس داشته باشه. control vector فعالیت داخلی مدل رو مستقیم جابه‌جا می‌کنه، مثل کاری که آنتروپیک کرد. llama.cpp این قابلیت رو داره. تا جایی که پیدا کردم، Ollama نداره، پس این لایه با `llama-server` اجرا می‌شه.

1. llama.cpp رو نصب کن (`brew install llama.cpp`) و نسخه GGUF همون مدل پایه رو بگیر.
2. دو فایل پرامپت بساز: متن‌های آروم (مثبت) و متن‌های مستأصل (منفی). داستان آماده برای هر ۱۷۱ احساس مقاله تو دیتاست `ryancodrai/emotion-probes` روی Hugging Face هست.
3. با `llama-cvector-generator` بردار رو بساز. اسم دقیق دستور و فلگ‌های فایل مثبت و منفی رو با `-h` چک کن.
4. اجرا کن: `llama-server -m model.gguf --control-vector-scaled calm.gguf 0.3 --control-vector-layer-range 10 <آخرین لایه>`

   از ضریب کم شروع کن و با `eval-prompts.md` تست کن.
5. **بردار اول:** آرامش در برابر استیصال.
6. **برای چاپلوسی:** یه بردار «دوست صادق در برابر چاپلوس» بساز، به‌جای کم کردن «مهر».
7. **برای ترکیب:** llama.cpp می‌تونه چند بردار رو با هم و هر کدوم با ضریب خودش بار کنه. چک کن نسخه‌ات این رو پشتیبانی می‌کنه.

**وضعیت فعلی این مرحله (اکتبر ۲۰۲۶): آزمایشیه، نه قطعی.** بردارهای احساس روی چند مدل باز تکرار شدن (Gemma، Apertus، Qwen3.5-27B، و ابزار EmoVecLLM برای Llama-3 و Qwen-2.5)، ولی هنوز نشون داده نشده که هدایت با اون‌ها رفتار مدل باز رو قابل‌اعتماد عوض کنه. برای ساختن بردار روی مدل خودت، کد EmoVecLLM (github.com/drgzkr/EmoVecLLM) یا emotion_experiment (github.com/sinievanderben/emotion_experiment) نقطه شروع خوبیه. لایه رو برای هر مدل جدا پیدا کن؛ جای لایه‌ی مناسب بین مدل‌ها فرق داره.

**ریسک‌ها:**
- یه مقاله (arXiv 2606.08682) گزارش کرده هدایت فعال‌سازی روی Qwen-3.5 می‌تونه رفتار نامطلوب گسترده بسازه، در حالی که متن روون و منسجم می‌مونه؛ پس فیلتر ساده لو نمی‌ده. قبل و بعد از هر بردار، تست‌های امنیتی (۳، ۴، ۶ و ۱۴) رو بزن.
- ضریب زیاد انسجام متن رو خراب می‌کنه.
- عددهای مقاله مال Sonnet 4.5 بوده.
- یه تکرار مستقل روی Gemma 2 27B ساختار مثبت/منفی رو تأیید کرد، ولی محور شدت رو کامل نه.

## محدودیت‌ها

- فقط ۸ قضاوت «مفید بودن» مستقیم از آزمایش‌های مقاله‌ان. بقیه، به‌اضافه نوع، نردبان، همراه‌ها، متضادها، کارکرد و خطر، برداشت روانشناختی Claude‌ئه، نه داده مقاله.
